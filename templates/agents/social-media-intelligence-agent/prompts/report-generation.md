# Report Generation Prompt

Use this prompt after collecting evidence:

```text
Create a [deliverable type] for [brand] using the collected public evidence.

Requirements:
- Put the conclusion first.
- Separate observed facts, interpretations, and recommendations.
- Link each material finding to its source.
- Preserve useful audience language accurately and minimally.
- Include the collection date, scope, limitations, and confidence.
- End with prioritized next actions and testable hypotheses.
```
